# Criterios y preferencias

## Fijos de la plataforma

- Puntuación numérica creciente con final natural (leaderboard).
- Canvas 4:3, una pantalla, sin assets pesados.
- Teclado y táctil.
- Diversidad de categorías en el catálogo. El color sale de la categoría (SHOOTER=cyan, PUZZLE=magenta, ARCADE=yellow); `green` solo para una categoría nueva.
